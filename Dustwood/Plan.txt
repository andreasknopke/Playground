# DUSTWOOD GULCH — Authoritative Build Spec (DESIGN.md)
Single source of truth for the Wild-West FPS. Supersedes any earlier plan. Every number, name and signature here wins. Implementers read §0–§2 completely, then the sections for their modules.
## Environment (verified 2026-09-17)
three r185 at vendor/three/three.module.js, addons at vendor/three/addons/ (SMAAPass() takes no args; UnrealBloomPass(resolution, strength, radius, threshold); OutputPass(); ShaderPass(shader, textureID); EffectComposer(renderer); BufferGeometryUtils.mergeGeometries(geoms, useGroups); SimplexNoise; OrbitControls all exist). Node 22, node serve.js 8080, Playwright headless Chromium with SwiftShader WebGL2. test/harness.js calls window.__game.step(dt) with dt in seconds. Not a git repo. No bundler, no TypeScript, no framework, no external asset files, no network requests at runtime.

## 1. SHARED CONVENTIONS
### 1.1 Units, axes, frames
* 1 unit = 1 metre, seconds, radians (degrees only in constants fields with a Deg suffix). Y up, right-handed.
* X runs along Main Street. −X = west (town entrance), +X = east (Sheriff's office). Z across the street; south = −Z, north = +Z.
* Origin (0,0,0) = centre of the street at the Saloon. Street floor y = 0.
* Yaw/pitch: yaw about +Y, pitch about +X, camera.rotation.order = 'YXZ', camera.rotation.set(pitch, yaw, roll). forward = (−sin yaw, 0, −cos yaw), right = (cos yaw, 0, −sin yaw). yaw 0 looks −Z; yaw = −π/2 looks +X (toward the Sheriff's office); yaw = +π/2 looks −X (toward the entrance); yaw = π looks +Z. pitch ∈ [−1.45, +1.45], positive = up. utils.yawFromDir(dx, dz) = Math.atan2(−dx, −dz).
* Player: capsule radius 0.35, height 1.80, eye height 1.65 (feet at pos.y = floorHeightAt).
* Enemy body radius = ENEMY_TYPES[type].radius (window 0.35, roof 0.35, barricade 0.40).

### 1.3 Walkable floor — town.floorHeightAt(x, z)
Returns floor height or null. Implemented analytically in town.js:
```
if (x ≥ −60 && x ≤ 60 && |z| ≤ 6.0) → 0 // street
if (x ≥ −60 && x ≤ 60 && 6.0 < |z| ≤ 8.0) → 0 // boardwalks
if (x ≥ −60 && x ≤ 60 && 8.0 < |z| ≤ 14.0) → 0 // building lots (walkable between buildings)
else → null
```
town.walkable = same regions as rects for clamping. Buildings register colliders so the player cannot walk through them.
### 1.4 Colliders (collision.js)
```js
/** @typedef {{type:'box', min:[x,y,z], max:[x,y,z], tag:string, surface:Surface, mask:number, id:number}} BoxCollider */
/** @typedef {{type:'cyl', x:number, z:number, r:number, y0:number, y1:number, tag:string, surface:Surface, mask:number, id:number}} CylCollider */
/** Surface = 'wood'|'adobe'|'sand'|'metal'|'glass'|'stone'|'none' */
MASK = { PLAYER:1, ENEMY:2, BULLET:4, NAV:8, SOLID:15, WALKERS:3 }
```
* Movement is 2-D in XZ; a mover of radius r at feet height y participates only with colliders whose [min.y, max.y] overlaps [y + 0.05, y + 1.0].
* Static colliders registered in init() by town.js and props.js.
* Broad phase: statics bucketed into 8 m slabs along X.
### 1.5 Nav grid (nav.js)
Uniform grid, cell 0.5 m, origin (−60, −6), 240 columns (x ∈ [−60, 60]) × 24 rows (z ∈ [−6, 6]). Cell blocked if floorHeightAt(cellCentre) === null or any MASK.NAV collider inflated by NAV.agentRadius = 0.3 overlaps it. Flow field = Dijkstra from the player's cell over 8-connected cells. Recomputed when the player's cell changes, at most every 0.25 s. Enemies read nav.flowAt(x, z, out). Boot-time assertion: Dijkstra from PLAYER_SPAWN gives finite distanceAt at every barricade anchor and every building anchor point.
### 1.6 Anchor points (enemy spawn)
```js
/** @typedef {{ id:string, kind:'window'|'roof'|'barricade', pos:THREE.Vector3, yaw:number, cover:THREE.Vector3, building:string }} Anchor */
```
Each building module exposes anchors: window (inside a window frame, leans out), roof (on a roof/balcony/hayloft/tower), barricade (behind a barricade). Enemy population table (§1.13 ENEMY_POP): Saloon = 3–4 window + 1 balcony roof; Livery = 1 hayloft roof; Church = 1 tower roof; Sheriff = 2 barricade + 2 window. Guaranteed ≥ 10 houses.
### 1.7 Update loop and deterministic stepping (main.js)
FIXED_DT = 1/60, MAX_SUBSTEPS = 4.
```
frame(nowMs): // requestAnimationFrame (real-time mode only)
dtReal = clamp((nowMs − lastMs)/1000, 0, 0.1); lastMs = nowMs
if (!G.paused && !G.manual) acc += dtReal
n = 0; while (acc ≥ FIXED_DT && n < MAX_SUBSTEPS) { stepOnce(); acc −= FIXED_DT; n++ }
if (n === MAX_SUBSTEPS) acc = 0
renderOnce()
stepOnce(): // the ONLY place update() is called
G.time += FIXED_DT; G.frame++
input.update(); player.update(dt); nav.update(dt); weapons.update(dt); enemies.update(dt);
mission.update(dt); prisoner.update(dt); particles.update(dt); decals.update(dt);
lighting.update(dt); props.update(dt); audio.update(dt); hud.update(dt); debug.recordTick()
renderOnce():
player.render(); enemies.render(); weapons.render(); particles.render(); lighting.render(); post.render()
```
* No interpolation: rendering shows the state after the last tick.
* Manual stepping (G.manual = true): RAF does not advance the sim or render on its own; only checks G.renderDirty. __game.step(dt, n=1) runs n ticks then renders once. __game.setTime(t) ticks at 1/60 without rendering until G.time ≥ t, then renders once. __game.start() from script enables manual stepping by default.
* FPS/timing: real-time = EMA over last 30 RAF frames; manual = 1000/renderMs of renders actually performed. stepMs = EMA of last 60 stepOnce costs; renders = monotonic count; initMs = boot time.
* All gameplay time from dt and G.time. State machines use countdowns (this.t −= dt), never comparisons against G.time.
* Forbidden in systems: performance.now, Date.now, Math.random, requestAnimationFrame, setTimeout, setInterval, scene.add in update. Allowed: main.js (frame pacing, fps), audio.js (micro-jitter), hud.js (fps text), textures.js/materials.js/utils.bakeVertexAO at init only.

### 1.9 RNG and determinism
utils.mulberry32(seed) → rng() ∈ [0,1) with rng.range(a,b), rng.int(n), rng.pick(arr), rng.sign(), rng.gauss(), rng.seed(n), rng.state(). Two generators: G.rngBuild (seed = ?seed= or 1337, all procedural construction) and G.rng (gameplay: spawns, spread, AI jitter, effects; reseeded by __game.seed(n) without rebuilding textures). Two runs with same seed + API sequence produce identical getState(), getEnemies(), getEvents().
### 1.10 Pooling
utils.Pool(capacity, factory): acquire() (steals oldest when exhausted), tryAcquire(), release(item), forEachActive(fn), reset(). Everything runtime-spawned is pooled and pre-added to the scene in init(): enemies (24), tracers (96), casings (64), particles (2 × 4096 GPU), smoke sprites (48), muzzle flash planes (3), decals (holes 256 / splats 128 / pools 24), blob shadows (40). Pools reset() on restart. No geometry/material creation after init(). Warm-up render (§2.3) with one instance of everything showing before pools empty themselves.

### 1.12 Code conventions
* ES2022 modules, named exports only. import * as THREE from 'three'; addons via 'three/addons/<path>.js'. 2-space indent, semicolons, const by default. JSDoc typedefs for exported shapes.
* Every system exports one class: constructor(G), init(), update(dt), optional render(), reset(), dispose(). Systems never import other system modules; they reach each other via G.<system> and G.bus. Leaf modules (importable by anyone): constants.js, bus.js, utils.js, collision.js, textures.js, materials.js. Helper modules importable only by their owner: rig.js (enemies), viewmodels.js (weapons).
* Module-level scratch: const _v1 = new THREE.Vector3(); — no allocations in update/render.
* Scene-graph rules: createContext does scene.add(camera); every light and SpotLight.target is a direct child of scene; nothing that must keep rendering is ever parented under an object whose visible flag changes.
* Layers (LAYERS): viewmodel meshes layers.set(LAYERS.VIEWMODEL) exclusively; effect pools, decals, blob shadows, enemies layers.set(LAYERS.NO_ENV) exclusively; main camera layers.enable(VIEWMODEL) + enable(NO_ENV); env-capture CubeCamera renders layer 0 only.
* Static meshes: matrixAutoUpdate = false, updateMatrix() once. Per-frame instanced pools: instanceMatrix.setUsage(DynamicDrawUsage).
* Colours: hex ints; colour textures colorSpace = SRGBColorSpace; data textures NoColorSpace.
* If a spec point is ambiguous, pick the simplest reading that keeps the API and add // DESIGN NOTE: at the top of the module.

Error capture: global error/unhandledrejection/console.error mirrored into __game.errors[]; exceptions inside stepOnce caught, pushed, rethrown once. Module loading: main.js imports each system with await import('./x.js') in try/catch → NullSystem on failure. FPS: real-time = EMA over 30 RAF frames; manual = 1000/renderMs. Standalone: node serve.js 8080, open /?debug=1; ?viewer=1 = no enemies/mission, OrbitControls fly-through.

## 4. GAMEPLAY SPEC
Pillars in priority order: (1) gun feel — every shot produces a tracer, a flash that lights the porch, a camera kick, a viewmodel kick, a casing, a sound, an impact in wood/dust; (2) readable enemies — window lights up, roof silhouette moves, barricade shakes; (3) the town is the show-piece — pushing down Main Street feels like a western movie; (4) push to the jail — curated escalation, last 20 m before the Sheriff's office are the climax.
### 4.1 Player controller (player.js)
4.1.1 Look: mouse deltas × PLAYER.mouseSens. pitch clamped ±PLAYER.maxPitch. Final camera rotation = base + recoil + bob/roll + shake. FOV 75 (sprint 80 over 0.2 s). Attract mode on the start screen (real-time only): yaw drifts ±10° at 0.05 Hz.
4.1.2 Movement: walk/sprint 4.2/6.6 m/s (sprint needs input.move.y > 0.3); backpedal & pure strafe factor 0.85; accel 40 m/s², friction vel *= exp(−12·dt); capsule r 0.35, height 1.8; step height 0.35; no gravity/jump/crouch in Tier 1. Desired velocity = normalize(move.x·right + move.y·forward) · speed. Sprinting: FOV up, bob up, viewmodel to sprint pose, cannot fire.
4.1.3 Collision (each tick, after integration): 1. y = floorHeightAt(x, z); if null → revert (try X-only / Z-only moves). 2. colliders.resolveCircle(pos, 0.35, MASK.PLAYER, pos.y). 3. Enemies within 2 m → push player 30 %, enemy 70 %. 4. Ensure floorHeightAt still non-null.
4.1.4 Head bob, roll, viewmodel sway: bobPhase += 2π·f·dt while moving (f = 1.9 Hz walk, 2.6 sprint); vertical A_v·|sin φ| (0.035/0.05), lateral A_l·sin(φ/2) (0.02/0.03), roll 0.6°·strafe + 0.35°·sin(φ/2) sprinting. Footstep on each zero crossing. Viewmodel sway: swayYaw += (−dx·0.0006 − swayYaw)·min(1, 12dt) clamped ±0.06 rad; breathing y += 0.002·sin(2π·0.3·t); walk x += 0.006·sin(φ/2), y −= 0.004·|sin φ|.
4.1.5 Health: max 100; regen 5 HP/s after 6 s without damage; low-health ≤ 30 (G.lowHealth = clamp((30 − h)/30)).

4.2.2 State machine: ready | firing | breaking | reloading | lowering | raising | holstered.
* ready → firing when trigger (semi: fireJustPressed, or buffered ≤ 80 ms) && mag > 0 && cooldown ≤ 0 && canFire. Fires this tick, cooldown = 60/rpm; back to ready next tick (revolver/rifle) or breaking for 0.80 s (shotgun; hull ejected at 0.25 s).
* Trigger on empty → weapon-empty (dryFire, rate-limited 4/s) and auto-reload after 0.25 s if reserve > 0.
* ready|breaking → reloading on R when mag < magSize && reserve > 0. Revolver/rifle: at 70 % of duration n = min(magSize − mag, reserve) transfers. Shotgun: start → shell loop → end. Firing, switching or sprinting cancels after the current shell.
* any → lowering (t_lower) → raising (t_raise) → ready on switch. index/current/getState().weapon flip to the target on the tick the switch is requested.
* Sprint keeps ready but canFire = false.
4.2.3 Firing a shot: origin = eye; baseDir = camera forward INCLUDING recoil offsets. For i in pellets: dir = perturb(baseDir, spreadDeg [+ patternOffset(i) rotated by a random per-shot angle for the shotgun]); hit = trace(origin, dir, BALLISTICS.maxDist); tracer from muzzleWorld (+ forward·0.15) to hit.point unless dist < 1.5 m; enemy hit → enemies.applyDamage; world hit → emit shot-hit-world. mag−−; bloom += bloomDeg; recoil kick; viewmodel kick; particles.muzzleFlash; lighting.flashMuzzle; particles.ejectCasing; emit shot-fired; stats.shotsFired++; hud.onShot(). spreadDeg = base + moveAdd·clamp(|vel|/walkSpeed, 0, 1.4) + bloom. Shotgun pattern: pellet 0 on axis, pellets 1–3 at 1.6°, pellets 4–8 at 2.3°, rotated by one random per-shot angle, jittered inside a 0.3° disc. Guarantee: pattern-only cone ≤ 2.6° → 0.159 m at 3.5 m; pattern + aim spread ≤ 3.4° → 0.178 m at 3.0 m, inside the 0.20 m chest capsule → all 9 pellets hit a standing target at ≤ 3.0 m regardless of seed.
4.2.4 Reload / break / switch timelines (poses in viewmodels.js; sfx cue times):
* Revolver (t ∈ [0,1] of 2.2 s / 2.6 s empty): 0–0.20 roll left 25°, pitch down 10°, move (−0.02, −0.03, +0.02), off-hand to the cylinder (reloadStart at 0.02); 0.20–0.30 cylinder swings out (cylinderOut at 0.22); 0.30–0.75 off-hand dips out and returns with fresh rounds; 0.75–0.85 rounds insert (roundsIn at 0.83; transfer at 0.70); 0.85–1.0 cylinder swings back, return. Empty: 0.85–0.92 hammer pulled back, 0.92–0.97 snaps forward (hammerRack at 0.95).
* Rifle (2.4 / 2.8 s): tilt right 20°; lever down + rounds out 0.15–0.30; hand away/back 0.30–0.70; rounds rock in 0.70–0.85 (roundsIn 0.82; transfer at 0.70); tap 0.85–0.90; return. Empty: lever back 0.05 then release (leverRack) 0.90–0.97.
* Shotgun: start (0.35 s) roll right 30° so the port faces the camera; each shell (0.55 s): shell mesh from below to the port (0–0.35), push in (0.35–0.45, shellInsert, ammo +1 at 0.33 s), hand retreats; end (0.40 s): roll back, breakShort if the reload started with mag == 0.
* Break (0.80 s): barrels break open (0.10–0.30, breakOpen 0.12, hull at 0.25), hold (0.30–0.45), close (0.45–0.65, breakClose 0.55); the gun dips 0.01 and rolls 3°.
* Switch: lowering = translate (0, −0.25, 0) + pitch −35° ease-in over lower; raising = reverse with ease-out-back 1.2.
4.2.5 Camera recoil: on a shot, target.pitch += kickPitch; target.yaw += kickYaw; target.roll += kickRoll. Applied offset moves toward the target over the ramp time. Recovery starts RECOIL.holdTime after the last shot: target *= exp(−dt/τ), τ = recovery/3. While the player pulls the mouse down during recovery, consume the pull from target.pitch first.
4.2.6 Viewmodel kick springs: vel.pos.z += kickBack·k1; vel.rot.x += kickUp·k2; vel.rot.z += rng(−1,1)·kickUp·0.3; vel.pos.x += rng(−1,1)·kickBack·0.25; acc = −K·offset − D·vel with RECOIL.vmSpringK/D.
### 4.3 Ballistics and hit feedback
trace(origin, dir, maxDist): world = colliders.raycast(origin, dir, maxDist, MASK.BULLET); enemy = enemies.raycast(origin, dir, world ? world.dist : maxDist, _enemyHit); return the nearer. No penetration; corpses not hittable. Enemy raycast: bounding sphere at the pelvis then the 17 capsules, head first, nearest wins. Cost target < 0.05 ms with 24 enemies.
Damage: dmg = weapon.damage × mult(group) × falloff(dist), mult(head) = min(weapon.headMult, def.headMultCap), torso 1.0, arm/leg 0.75; falloff = 1 up to fullRange, lerp to minFactor at minRange. enemies.applyDamage returns {killed, headshot, staggered}.
Feedback: HUD hit marker (white body / yellow head / red + 30 % larger on kill; shotgun one marker per shot by best outcome), hitMarker sounds, enemy flinch, blood burst, crosshair contracts 15 % for 100 ms. No damage numbers, no health bars.
Stats (G.stats): shotsFired, shotsHit, headshots, kills, killsByType, damageDealt, damageTaken, sectorsCleared, timeSurvived; accuracy = shotsHit/shotsFired.
### 4.4 Effects (particles.js + decals.js) — all pooled, zero runtime allocation

Rifle adds 2 side cards (40 ms). Plus the muzzle light, 1 smoke puff (shotgun 3), every 4th rifle shot and every shotgun shot 2–3 embers.
4.4.2 Tracers: InstancedMesh(96) of a unit cylinder along +Z, MAT.tracer, instanceColor brightness ×2.5. Spawn from S = muzzle world (+ forward·0.15) to E = hit point (or 120 m); skip if dist < 1.5 m. Speed 280 m/s; total time clamped [35, 110] ms. Per tick head = min(dist, v·age), tail = max(0, head − len); place from S + dir·tail to S + dir·head. Shotgun: 9 instances of radius 0.006, len 0.5. frustumCulled = false.
4.4.3 Casings: InstancedMesh(64) cylinders: 44 r 0.0045 × 0.019, 12 ga hull r 0.0095 × 0.06 red. Gravity 9.81; on y ≤ floorHeightAt + r: vy × −0.35, vxz × 0.7, ω × 0.5; casingBounce on the first two bounces within 6 m; rest after 3 bounces or |v| < 0.15; life 8 s then shrink 0.3 s.
4.4.4 Impacts (by surface) — particles.impact(pos, normal, surface, weapon); decals & audio listen to shot-hit-world:
| Surface | Particles | Puff | Decal | Sound |
|---|---|---|---|---|
| wood | 5–8 tan splinters 0.5 s | light brown puff | hole 0.05 | impactWood |
| adobe | 6–10 grey chips 0.01 m | dust 2 sprites | dark chip 0.06 | impactAdobe |
| sand | 6–10 dust chips | dust 2 sprites | dust mark 0.06 | impactSand |
| metal | 10–16 additive sparks | tiny grey puff | scratch 0.04 | impactMetal (20 % ricochet) |
| glass | 8 white-cyan shards | none | crack star 0.12 | impactGlass |
| none (edge) | nothing | | | |
4.4.5 Blood: burst 8–14 particles (0.006–0.014 m, colour (0.35, 0.02, 0.02)) along the reflected dir ±60° at 1.5–4 m/s, gravity, 0.5 s + 2 mist sprites. Headshot kills: 24 particles + 4 mist upward. Floor splat decal under the hit. Death pool: decals listens to enemy-rest and adds the pool FX.poolDelay later; grows 0.2 → 1.2 m over 3 s. Keep blood dark (#4a0a0a).
4.4.6 Effects budget: worst case (shotgun on metal at 3 m): 3 flash planes + 1 light + 3 smoke + 9 tracers + 1 hull + 9 × 12 sparks + 9 decals — all pooled. Effects draw calls ≤ 10.
### 4.5 Enemies — archetypes, anchored AI (enemies.js)
4.5.1 Archetypes (authoritative in constants.ENEMY_TYPES):
| | Window Shooter | Roof Sniper | Barricade Shotgunner |
|---|---|---|---|
| Silhouette | 1.75 m, leans out of a window frame, bandana | 1.75 m, crouched on a roof/balcony/hayloft/tower, rifle | 1.8 m, hunched behind a barricade, shotgun |
| HP | 60 | 80 | 100 |
| Radius | 0.35 | 0.35 | 0.40 |
| Anchor | window | roof | barricade |
| Points | 1 | 2 | 3 |
| Vocal pitch | 0.9–1.1 | 1.1–1.3 | 0.7–0.9 |
| Fire range | 45 m | 45 m | 25 m (shotgun) |
| Damage | 8–12 | 10–14 | 12–16 (shotgun spread) |
| Fire accuracy | 0.5–2.0° | 0.5–1.5° | 1.0–3.0° |
Per-instance at spawn (G.rng): height scale 0.94–1.06, tint ±10 % L, phase offset, vocal timer.
4.5.2 State machine (anchored):
```
inactive → idle (at anchor, hidden behind cover) → peek (lean out) → aim → fire → duck → reload → peek …
→ dead (fall) → corpse → sinking → inactive
```
* idle: hidden behind cover (window: inside the frame; roof: prone; barricade: crouched behind). Not hittable.
* peek: lean out over peekTime (window: rise into the frame; roof: raise head; barricade: rise above the barricade). Becomes hittable. Emits enemy-peek.
* aim: track the player, aimTime, then fire.
* fire: one shot (or shotgun blast), fireTime 0.1 s. Emits shot-fired (enemy variant).
* duck: drop back behind cover over duckTime. Not hittable.
* reload: after a magazine of shots, reloadTime, then peek again.
* dead: emit enemy-killed, death animation, removed from steering/collision; corpse 9 s then sinks → inactive.
* Targeting: only the player; enemies always know where the player is (no perception model).
* LOD: beyond ENEMY.lodDistance animate every 2nd tick; behind the camera skip animation.
* Vocals: per-enemy timer rng.range(3, 9) s → enemy-vocal when within 25 m; growl at aim; hurt grunt rate-limited 0.25 s; death vocal; global cap 6 voices.
4.5.3 Anchored behaviour: enemies never move from their anchor (no NavMesh). They lean out, shoot, duck. The barricade shakes when the shotgunner fires (visual). Window lights up when a window shooter peeks (emissive flash). Roof silhouette moves (animation).
### 4.6 Mission director and the push (mission.js + prisoner.js)
4.6.1 States: idle → intro (2.0 s banner) → active (sector 1) → sectorClear (3.0 s banner) → active (sector 2) → … → showdown (Saloon Showdown, midpoint set-piece) → finalPush → win | lose.
Sector progression: sector 1 (TOWN ENTRANCE, x −60…−40), sector 2 (MAIN STREET, x −40…−6), sector 3 (SALOON SHOWDOWN, x −6…10), sector 4 (FINAL PUSH, x 10…56). A sector clears when its queue is empty and aliveCount === 0. Sector 3 is the Saloon Showdown: the Saloon's window shooters + balcony sniper activate together, a set-piece with a banner. Sector 4 is the final push: Sheriff's barricade shotgunners + window shooters, the last 20 m before the Sheriff's office are the climax.
4.6.2 Spawn queue: each sector builds queue = [{type, anchorId}] of config.count entries (constrained shuffle, G.rng). Spawns held while aliveCount ≥ maxAlive. Enemy population per §1.13 ENEMY_POP.
4.6.3 Win/lose: Win when the prisoner is freed (prisoner-freed). Lose when the player dies (player-death) or the prisoner dies (prisoner-death). game-over / game-win events.
4.6.4 Prisoner: state locked/free/dead. Key on the Sheriff's desk (or dropped by the last barricade shotgunner). F on key → keyHeld; F on cell door → unlock; F on prisoner → free ⇒ Win. Shooting the lock also unlocks. Prisoner death (enemy fire) ⇒ Lose.
4.6.5 Score/kills: kills counts bodies (HUD). score = Σ points × (headshot ? 2 : 1).
### 4.7 Player damage, death, game over, restart
* applyDamage: health −= amount (god mode skips), lastDamage = 0, player-hit (HUD vignette flash, directional arc, playerHurt sfx rate-limited 0.2 s), camera shake 0.5° for 0.2 s, knockback vel += normalize(pos − from)·knockback, viewmodel jolt 0.02 m down. health ≤ 30: heartbeat loop, master low-pass 0.35 duck, grade desaturation.
* Death (health ≤ 0): dead = true, player-death {reason}; camera pitch → −35°, eye → 0.45 m over 0.8 s, roll → 20°, viewmodel drops out; world keeps simulating 1.5 s then freezes; HUD fades; after 1.5 s #gameover shows "YOU DIED" + stats; pointer lock released; gameOver sfx.
* Restart (R / click / Enter / __game.restart()): full soft reset (§2.3) → intro(1). RNG not reseeded unless seed() is called.

## 5. HUMANOID RIG AND ANIMATION (rig.js / enemies.js)
One SkinnedMesh per enemy (one draw call), procedurally built skeleton, rigid binding, animation = bone rotations computed per tick by layered clip functions. No physics engine; deaths are kinematic.
5.1 Bone hierarchy (21 THREE.Bone, bone-local offsets in metres at scale 1; depth-first order = BONE_NAMES): root (Group: pos = enemy.pos, rotation.y = yaw, scale = def.scale × bodyScale; local forward = −Z) → pelvis (0, 0.96·legScale, 0) → spine (0, 0.14, 0) → chest (0, 0.20, 0) → neck (0, 0.26, 0) → head (0, 0.10, 0); shoulders → upperArmL/R → lowerArmL/R → handL/R; hips → upperLegL/R → lowerLegL/R → footL/R. Same as Fable §5.1.
5.2 Parts (17, rigidly bound; partId attribute; atlas quadrant UV remap): pelvis, spine, chest, neck, head, upperArmL/R, lowerArmL/R, handL/R, upperLegL/R, lowerLegL/R, footL/R. Extras merged: bandana (window), hat (roof), shotgun strap (barricade). ~2.6–3.2 k tris total.
5.3 Hit capsules (bone-local a, b, r; world via bone.matrixWorld): same table as Fable §5.3. PART_GROUP: head, neck → head; chest, spine, pelvis → torso; arms/hands → arm; legs/feet → leg. Capsule world data refreshed once per tick inside enemies.update(), after the pose is applied, into enemy.capsules (Float32Array 17 × 7) — never in render(). hitVolumeCenter(enemy, 'torso') = the world midpoint of the chest capsule; 'head' = the head capsule midpoint. Test order: head first, then torso, then limbs; nearest hit wins.
5.4 Textures per variant (textures.js enemyAtlas): skin generator (512²), cloth, face (front quadrant), bandana/hat/strap. Same recipe as Fable §5.4.
5.5 Animation layers: pose buffer Float32Array(21 × 3) Euler XYZ per bone + extras. Final pose = weighted blend of active clips, then flinch spring, then applyPose. Clips: idle (breathing, weight shift), peek (rise into the frame), aim (track the player, rifle raised), fire (recoil), duck (drop behind cover), reload (lever/cylinder/break motion), flinch (additive spring), death (kinematic fall), corpse (still). speedRatio = 0 (anchored — no locomotion).
5.6 Death (kinematic): pick back if the killing hit came from the front and was strong; forward if killed while speedRatio > 0.5; else crumple. Same recipe as Fable §5.6. After landing: ENEMY.restTwitchTime = 0.4 s of small twitches then still → emit enemy-rest. Headshot kills: head part scaled to 0 + big burst [T2]. bodyThud when the body lands. Sink: rootY → −ENEMY.sinkDepth over sinkTime, then release.
5.7 Blob shadows: particles.setBlob(enemy.blobIndex, pos, 0.45·scale, alpha); alpha 0.5 alive, fades with the sink. Player uses blob index 0.

## 6. THE PUSH (mission.js) — choreography
The push is the mission director's timeline. Sector 1 (entrance): 2 window shooters in the first houses + 1 barricade shotgunner at the overturned wagon. Sector 2 (main street): 2 window shooters + 1 roof sniper (a house roof). ## 7. AUDIO (audio.js) — everything synthesized with WebAudio at init; no files
7.1 Graph: voices → sfxBus (Gain 1.0) → duckFilter (BiquadFilter lowpass, 20 kHz) → master (Gain 0.8) → compressor → destination; sfxBus → reverbSend (Gain 0.25) → convolver → reverbReturn; loops → ambBus (Gain 0.7); ui → uiBus (Gain 0.6) → master. Impulse response: procedural stereo 2.2 s, noise · e^(−3.2t) with a one-pole low-pass sweeping 7 kHz → 900 Hz + 6 early reflections — "wooden hall", RT60 ≈ 1.6 s, pre-delay 15 ms. Noise buffers (white, pink, brown; 2 s, looped) pre-generated. AudioContext created only in unlock() (latencyHint:'interactive'); disable() never creates one; headless starts disabled unless __game.enableAudio(). Voices: play() builds a small node graph, cap 32 voices in flight (LRU-steal), per-name rate limit 25 ms. Positional (opts.pos): one of 24 pooled PannerNodes. Priority when starved: weapon > player hurt > enemy fire > impacts > steps > groans. Audio never affects state; may use Math.random() for micro-jitter.

> ## The game
> A first-person shooter set in a single, beautifully detailed underground
> subway station. The player is trapped on an island platform between two
> tracks when an outbreak reaches the station. They fight waves of the undead
> until they die; there is no win state. Progression is driven by trains:
> after a quiet first wave, a train pulls in, opens its doors, and unloads
> the next wave. Later waves arrive the same way, escalating in number,
> toughness and speed. The only goal is to survive as long as possible.

> - Fully headless-testable and scriptable.

> ## Creative direction
> Early-20th-century two-track station. An island platform with tiled walls
> across both tracks carrying a green mosaic band with the station name; two

> look flat-lit — alternating pools of light are its identity. Lean into
> grime, wear, litter and lived-in detail.

> ## Gameplay pillars (priority order)
> 1. Gun feel — every shot produces a tracer, a flash that lights the scene,
> camera kick, weapon kick, a shell casing, a synthesized sound and an impact
> on the world.
> 2. Readable enemies — a few clearly distinguishable silhouettes and
> behaviours, legible at distance.
> 3. The train is the show-piece — its arrival should be a scripted,
> cinematic, dramatic set piece.
> 4. Escalation until death — no win state; difficulty keeps climbing.
